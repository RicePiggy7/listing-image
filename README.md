# Listing Image — 电商图智能生成

**从产品资料到可上架套图，完成传统流程需要 2-3 天的工作。**

上新一款产品，外包设计师报价 500-2000 元、交付周期 3-5 天；主图被 Amazon 拒审，改图又要等 1-2 天。这个 skill 把策划、文案、生图三个环节合并成一次对话：你提供产品资料，输出证据账本、成交驱动力诊断、完整 Storyboard、逐图执行卡和实际图片文件。

---

## 核心价值

### 解决什么问题

- **上新慢**：设计师排期、来回沟通、反复改稿，一套图 3-5 天
- **成本高**：外包 500-2000 元/套，内部设计师人力成本更高
- **质量不稳定**：合规踩坑（Amazon 白底/占比/禁用词）、卖点没抓准、套图风格不一致
- **被拒后返工**：平台拒审原因模糊，改图又要重新排期

### 这个 skill 怎么做

**输入**：产品名称 + 产品照 + 核心卖点（可选）

**10 分钟内输出**：
1. **证据账本** — 哪些卖点能用（已确认/有依据），哪些要补证，哪些禁止，避免编造和违规
2. **成交驱动力诊断** — 这个产品靠什么打动买家（视觉/痛点/参数/信任/情感/价格），决定套图重心
3. **Storyboard + 执行卡** — 每张图的任务、画面、图内文案、5-slot 生图 Prompt、证据来源
4. **实际图片** — 主图、场景图、卖点信息图等（有 API key 时），或可直接使用的 Prompt 包
5. **自审记录** — 五维 80 分线（证据与合规/转化逻辑/视觉层级/一致性/可执行性），不达标自动重写

**关键机制**：
- **证据分级** — 不编造数据/功效/认证，缺资料时标「待确认」而不是猜
- **平台合规预置** — 内置 Amazon/淘宝/TikTok Shop 等平台规则，白底/占比/禁用词自动检查
- **23 条失败模式护栏** — 从真实翻车案例提炼（卖点堆砌/参考图失真/促销造假/跳过自审等），生成前逐条自检

```
我要上架这款蓝牙耳机，平台 Amazon
```

- 确认或调整（比如「第 3 张改成对比图」）
- 生成完整执行卡和图片文件

## 还能做什么

### 图被拒/差评后诊断修复

提供现有图 + 平台拒信，输出 6 维度问题诊断（转化逻辑/视觉层级/证据合规/平台适配/文案画面一致性/风格漂移）和最小必要修改方案。

### 只要策划方案，不要图

输出证据账本 + 驱动力诊断 + Storyboard + 执行卡（含完整 Prompt），交给自己的设计师或外包团队执行。

### 变体套图批量生成

同一产品多个颜色/材质变体，保持统一风格和角度，只改颜色。

## 边界与局限

**不做**：
- listing 文案文档（标题、五点描述）— 只做图和图内文案
- 短视频/直播话术
- 自动上架或发布 — 只输出可直接上传的图片文件

**当前局限**：
- **A+ 内容** — 可输出策划方案和执行卡，但 A+ 模块尺寸（970×300 等）不符合生图引擎规则，不能直接生图，需人工排版
- **主图白底** — 通过 Prompt 约束 + 生成后视觉确认实现，不提供像素级白底保证（如 Amazon API 自动检测场景需人工后处理）

## 技术说明

<details>
<summary>依赖和配置</summary>

**依赖**：`jq`（JSON 处理工具）
- macOS: `brew install jq`
- Linux: `apt install jq` 或 `yum install jq`

**生图引擎**：`scripts/imagegen.sh`（支持 OpenAI GPT-Image-2/2.5，provider-agnostic 设计）

**环境变量**（有 API key 时）：
```bash
export IMAGE_API_BASE="https://api.openai.com"
export IMAGE_API_KEY="sk-xxx"
export IMAGE_MODEL="gpt-image-2.5-flare"
```

无 key 时用 `--mode manual` 导出 Prompt 包，自行生成。

**场景模板**：37 个预置场景（白底主图/场景图/卖点信息图/对比图/包装图/UGC/品牌故事等）

**知识层来源**：
- 策划方法论（证据账本/驱动力诊断/五维自审）来自真实电商案例提炼
- 执行卡格式、合规规则、文案质量自检、平台规则参考来自 feichanggege/ecommerce-visual-copywriting-skill（MIT）
- 23 条关键失败模式护栏来自真实翻车案例

</details>
